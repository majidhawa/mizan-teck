# Pagram ISP Website — Next.js + Tailwind Site

A modern marketing website for Pagram Internet Service Provider.

## Quick Start

```bash
npm install
npm run dev
# open http://localhost:3000
```

## Tech
- Next.js App Router
- Tailwind CSS
- Framer Motion, lucide-react (optional icons/animation)

## Pages
- `/` — Landing
- `/about`
- `/services`
- `/contacts`
- `/faqs`
